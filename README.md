## Inboard 是什么？

Inboard 是一款专为 Mac 打造的图片素材管理工具。开发团队的核心理念只有一条：**做减法**。

大多数同类软件恨不得把所有功能都塞进去，Inboard 反其道而行之——只保留「收集素材」和「整理素材」两件事，其他统统不要。界面干净，上手几乎没有学习成本。

对于每天和大量图片打交道的设计师、摄影师、前端开发者来说，这种克制感反而是最大的优点。

## 用起来是什么感觉？

打开 Inboard，迎面而来的是一个类 Pinterest 的瀑布流界面。和网页版 Pinterest 不同的是，这里的图片全部存在本地，不依赖网络，加载速度是瞬间的。

翻图的时候，那种顺畅感真的不一样。

**收集素材的方式主要有两种：**

一是 **菜单栏截图工具**。想保存当前屏幕的内容，直接点一下 Menubar 里的图标截图，图片自动进库，URL 也会一并保存，以后找原页面只要一键就能跳回去。

二是 **Dribbble 直接联动**。如果你是 Dribbble 用户，可以直接把账号里 like 过的作品同步进来，不用一张张手动下载。对于经常在 Dribbble 找灵感的设计师来说，这个功能省了不少事。

---

## 管理素材靠什么？

Inboard 用的是「文件夹 + 标签」双维度管理体系，两者可以交叉使用。

比如你有一张深色系 UI 截图，既可以放在「移动端项目」的文件夹里，又可以同时打上「深色」「iOS」「卡片设计」三个标签。日后搜标签，多张图片瞬间汇集，不用翻文件夹层级。

标签数量没有上限，可以自己玩出各种组合方式。

右侧预览面板支持重命名、添加 URL、修改标签。双击图片进入全屏预览，在一个精美的大格子界面里看图，比在 Finder 里看那一堆小缩略图，体验差了不止一个档次。

---

## 支持哪些文件格式？

Inboard 支持的格式覆盖了设计日常所需的主流格式：

**PNG、JPG、GIF、PSD、AI、EPS、TIFF、PDF**

有一点要说清楚：Inboard 不支持 Sketch 文件，如果你的工作流重度依赖 .sketch 源文件，这个需要注意。

---

## 数据迁移麻烦吗？

完全不麻烦。Inboard 以「库文件」的形式统一管理数据，换电脑的时候直接导出整个库，在新机器上导入就行了，素材、标签、文件夹结构全部保留。

这点对于隔段时间换设备的用户来说，体验非常友好。
